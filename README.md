# Profile — Telegram Mini App

Адаптивное мини-приложение для Telegram: профиль, коллекция внутренних игровых предметов, кастомизация и гарантированное улучшение редкости за игровые очки.

## Файлы
- `index.html` — разметка приложения
- `styles.css` — оформление
- `app.js` — логика профиля, коллекции и улучшений

## Публикация через GitHub Pages
1. Загрузите эти три файла в корень репозитория GitHub.
2. Откройте Settings → Pages.
3. В разделе Build and deployment выберите Deploy from a branch, ветку `main`, папку `/ (root)`, нажмите Save.
4. Дождитесь публикации. Адрес будет вида `https://ВАШ-ЛОГИН.github.io/profile-mini-app/`.
5. В @BotFather настройте Main Mini App / Web App и укажите этот HTTPS-адрес.

Предметы и настройки в этой демо-версии хранятся локально в браузере устройства. Для общей синхронизации между устройствами и постоянного хранения потребуется сервер и база данных.

## Безопасность
Не добавляйте токен Telegram-бота в эти файлы и не публикуйте его на GitHub.
